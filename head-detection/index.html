对照实验结论: 加入 general 图像后 recall 略升(0.9251→0.9308)但 precision 下降 (0.8717→0.8461), AP 基本持平(AP50 +0.0005, AP50-95 -0.0008)。对固定的教室测试集没有实质增益—— 因为起始模型已在 general 上学过通用头部特征,重复加入反而稀释了教室数据占比。

Task 1 标注工具 · Task 6 摄像头演示

标注工具 (Flask + Canvas)

增删改拖拽/缩放框、缩放、标签开关、上一张/下一张、保存到 annotations_edited/(不覆盖原文件)、导出 YOLO zip。

python -m annotator.app --images <dataset>/images/classroom/train \
    --labels <dataset>/labels/classroom/train --format yolo

摄像头演示

webcam.py: 实时框 + 置信度 + 帧率 + conf 滑杆。单帧推理示例(同模型管线):

python -m src.webcam --weights runs/finetune/weights/best.pt --camera 0

实测说明: 本机摄像头取景为空场景(8 帧均无人物)时检测数为 0,符合预期; 摄像头近景与教室俯拍视角存在差异(域差异),需要人物入镜才能演示。

复现步骤(GPU 机器)

install.bat cu124 (或其他 CUDA tag)          # 安装 CUDA 版 PyTorch + 依赖
python check_gpu.py                          # CUDA available: True
python -m src.data_check ...                 # Task 2 自动检查
python scripts/train_starting.py             # 起始检测器 (general, 本页替代版)
python -m src.predict  --weights runs/starting_general/weights/best.pt --images .../classroom/test --out runs/baseline/preds.json
python -m src.evaluate --images ... --labels ... --preds runs/baseline/preds.json --out runs/baseline/metrics.json
python -m src.visualize --images ... --labels ... --preds runs/baseline/preds.json --out runs/baseline/vis --worst 5
python -m src.train --weights runs/starting_general/weights/best.pt --data classroom --epochs 100 --name finetune
python -m src.train --weights runs/starting_general/weights/best.pt --data mixed     --epochs 100 --name finetune_mixed
python -m src.compare ...                    # Task 5 对比表
