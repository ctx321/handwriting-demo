01 · 项目与任务

六个任务，一条完整管线

  • Task 1 标注工具（Flask+Canvas）：增删改拖拽、缩放、保存/导出，不覆盖原标注
  • Task 2 数据检查：自动检查 + 60 张人工复核模板
  • Task 3 基准评测：起始模型在 test 上的 P/R、AP50、AP50-95、耗时
  • Task 4 微调：classroom 训练 + mixed 对照实验（唯一变量=数据）
  • Task 5 对比：同 5 张示例图 before/after
  • Task 6 摄像头演示：实时框 + conf 滑杆 + 帧率

对照实验结论：加入 general 图像后 recall 略升（0.9251→0.9308）、precision 下降 （0.8717→0.8461），AP 基本持平。对固定教室测试集没有实质增益——起始模型已含通用头部特征， 再混合反而稀释教室数据占比。成本：训练图数 +34%。

10 · Task 6

摄像头演示

  • python -m src.webcam --weights runs/finetune/weights/best.pt
  • 实时画框 + 置信度 + 检测数 + 帧率；滑杆只过滤预测，不重训
  • 低阈值→更多误检；高阈值→漏检增加
  • 域差异：教室俯拍 vs 摄像头近景，视角/尺度不同会掉精度（实测空场景 0 检出，符合预期）

12 · 结语

结论与不足

  • 微调把 AP50 从 0.830 提到 0.949，AP50-95 从 0.352 提到 0.474；主要的剩余错误是小目标与严重遮挡头部
  • mixed 对照实验无增益（诚实报告）；错误多集中在远景小头与相互遮挡
  • 起始 checkpoint 为自训练替代版（课程包未含）；正式对比需替换为 instructor 版本
  • 数据集按图片划分，不保证教室/视频级的独立性，泛化结论有局限
