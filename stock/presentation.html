01 · 研究问题

LSTM 能学会有用的收益模式吗？

  • 目标：用 LSTM 预测 7 只 ETF 未来 21 个交易日的收益
  • 输出：8 个非负权重（7 ETF + CASH，和 = 1），每 21 天调仓
  • 基准：QQQ 买入持有、7 只 ETF 等权；零成本、$10,000 初始资金
  • 约束：只用 ≤ 决策日的数据；冻结模型；不在推理时训练
  • 作业明确：击败 QQQ 不是完成条件，可解释的负结果同样有价值
02 · 数据

数据与切分

  • 2005-01-03 → 2023-12-29，共 4,781 个交易日
  • 7 只 ETF：QQQ / SPY / IWM / IEF / TLT / GLD / SHY
  • 市场指标：VIX（波动率）、IRX（13 周国库券收益率，少量缺失）
  • 时间切分：2005–2017 训练 / 2018–2020 验证 / 2021–2023 测试
  • 21 天标签在切分边界 purge 21 天，防止重叠泄漏
03 · 特征与标签

73 维特征，60 天窗口

  • 每只 ETF：1/5/20 日收益、60 日动量、12-1 动量
  • 波动率：20/60 日滚动标准差；均线比：P/MA20-1、P/MA60-1
  • 回撤：现价距 60 日高点；市场：VIX 对数与 5 日变化、IRX
  • 标准化参数 只在训练段拟合并冻结
  • 标签：P[t+21]/P[t] - 1（7 维）
04 · 模型与训练

LSTM(73→32) + LayerNorm + Linear(7)

  • 输入 (batch, 60, 73) → LSTM 32 隐层 → LayerNorm → Dropout 0.5 → Linear(7)
  • 损失 MSE（目标标准化）；Adam，lr 2e-4，batch 128，早停（25 轮无改善）
  • 训练样本：2,960（2006–2017）· 验证 735（2018–2020）· 测试 732（2021–2023）
  • 固定种子 42；权重衰减 5e-3；实际训练 46 轮后早停

06 · 预测质量

验证集优于基线，测试集没有优势

  • 验证集：LSTM 2.423e-3 < 零收益 2.542e-3 < 历史均值 2.432e-3
  • 测试集：LSTM 2.269e-3 > 零收益 2.103e-3
  • 结论：21 日收益的可预测性很弱，模型在 2021–2023 没有泛化优势
  • 这正是作业强调的：预测损失更低 ≠ 组合表现更好
07 · 配置规则

从预测到权重（无状态、可解释）

  • 风险调整打分：s = max(预测, 0) / max(σ₆₀, 0.5%)
  • 现金闸门：全部预测 ≤ 0 → 100% 现金
  • 归一化 + 单资产上限 40%；小于 3% 的仓位并入现金
  • 刻意不做换手平滑（API 无状态，无法获知上次权重）
  • 回测探索支持：逆波动率是唯一稳定的权重法，动量与均值方差族脆弱

10 · 局限与结论

诚实的结论

  • 21 日收益预测精度有限：验证集略优于零基线，测试集无优势
  • 组合仍在风险调整上跑赢等权（Sharpe 0.42 vs 0.18），但未跑赢 QQQ 总收益
  • 假设零成本；若引入手续费，需重新评估换手（本例已限制上限与碎片仓位）
  • 数据截止 2023-12-29；隐藏期行情结构变化可能进一步削弱效果
  • 改进方向：更多特征、状态切换模型、按波动率缩放的目标、集成模型
核心收获：把"预测 → 配置 → 契约 API → 永久网页"完整跑通，并诚实量化了模型能力的边界。
