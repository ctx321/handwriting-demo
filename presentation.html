A multi-layer perceptron is the simplest form of neural network: input → one hidden layer → output. Every neuron in a layer is connected to every neuron in the next, and the network "learns" by adjusting the strength of those connections (the weights).

What is the structure of the model?

784 input values flow through one hidden layer of 256 neurons, then a final layer of 10 neurons produces a score per digit. The diagram is schematic — in reality every node connects to every node in the next layer.

Mathematical form
A neuron computes a weighted sum of its inputs, adds a bias, and passes the result through an activation function (here ReLU) that introduces non-linearity. Without non-linearity, stacking layers would only ever equal one linear layer.

Train / validation loss curves

Cross-entropy loss per training epoch (same hyper-parameters as the deployed model). Validation = held-out MNIST images never used for gradient updates.

Training loss Validation loss

What to say: training loss keeps dropping toward 0, while validation loss bottoms out around epoch and then rises again. That widening gap is overfitting — the model memorises the training set and stops generalising. This is exactly why the real model uses early_stopping, which halts training near the best validation point.

Code that creates and trains the model

The whole learning loop in one file: load MNIST, build the MLPClassifier, fit() it, then save the trained model with joblib. The demo page runs this network fully in the browser — the second tab shows the JavaScript forward pass (784 → 256 ReLU → 10 softmax) and the preprocessing that mirrors the original Python pipeline.

Total training wall-time for the deployed model (~24 epochs, early stopping): about 2.5 minutes on CPU.
